# RenderCore Library
***
RenderCore is a library for combining and abstracting WinAPI and DirectX11 interfaces while leaving as much control as possible to the user.
\
It was created to help me learn about graphics programming, specifically DirectX11, and to become the base library behind my future graphics projects.
\
It is neither designed nor meant to be perfect. It is an everchanging learning resource for me and will, for the most part, only include features that are required by my other projects.
